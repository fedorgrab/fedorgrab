## Hi there 👋

Machine Learning Engineer | ML Systems & Infrastructure

I'm a machine learning engineer at the Broad Institute of MIT and Harvard, working on production ML systems and infrastructure for large-scale scientific data.

My work spans model training, embedding generation, vector search, distributed data processing, and ML benchmarking and evaluation.

## Selected Work

**[Cell Annotation Service (CAS)](https://www.cellarium.ai/tool/cellarium-cell-annotation-service-cas/)** — Production ML service for large-scale single-cell RNA-seq annotation, used by hundreds of researchers worldwide.

**Nexus** — Cloud-based platform for managing large-scale omics datasets, with distributed data processing and Kubeflow-orchestrated workflows.
